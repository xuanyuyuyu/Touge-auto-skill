# 头歌编程作业自动完成

用于自动完成 Educoder（头歌）课堂中的未通过编程作业。

## 功能

- 扫描作业列表，跳过已经通过的题目
- 按列表顺序逐题读取任务描述、效果图、代码模板和测试要求
- 支持 HTML、JavaScript、Python、Java、C/C++ 等常见编程任务
- 提交官方评测，并在失败时查看“测试结果”
- 对照预期输出、实际输出和任务效果图定位差异后再重试
- 使用一次性粘贴写入多行代码，避免编辑器自动缩进导致格式混乱
- 每题最多尝试三次，无法解决的题目会保留现场并记录原因

## 使用方法

1. 在 Codex 中安装或启用本 skill。
2. 登录 Educoder，并打开课程、作业或教学计划链接。
3. 直接发送类似下面的请求：

   > 用头歌编程作业自动完成 skill，完成这个链接中前 3 道未通过的题目：`https://www.educoder.net/...`

4. skill 会自动识别已通过题目并跳过，然后逐题完成、评测和诊断。

也可以指定单道题目：

> 完成这个头歌题目：`https://www.educoder.net/tasks/...`

## 执行原则

- 任务描述、编程要求和目标效果图优先于“相关知识”中的示例代码。
- 评测失败后，先打开“测试结果”，再重新查看目标效果图或效果标签，重点核对文字、数字、标点、空格、顺序和结构。
- 保留 `Begin-End` 之外的模板代码，不查看可能扣分的参考答案。
- 评测通过后不点击额外的“完成”按钮。

## 注意事项

- 需要浏览器中已有 Educoder 登录状态。
- 评测提交会影响平台作业记录，请确认使用的是正确账号和课程。
- 页面出现登录、验证码或权限问题时，需要用户先处理后再继续。
